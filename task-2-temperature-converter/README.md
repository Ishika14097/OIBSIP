# Atmospheric Temperature Converter

A responsive temperature converter built with HTML, CSS, and vanilla JavaScript. It converts values between Celsius, Fahrenheit, and Kelvin while adapting the atmospheric background and temperature status to the selected value.

## Features

- Converts between Celsius, Fahrenheit, and Kelvin
- Validates numeric input and absolute-zero limits
- Updates results when the input unit changes
- Interactive temperature scale with mouse, touch, and keyboard support
- Dynamic atmospheric background, status label, and particle effects
- Responsive layout for desktop and mobile screens
- Reduced-motion support

## Files

- `index.html` - Page structure and accessible controls
- `style.css` - Layout, responsive styling, scale styling, and visual effects
- `script.js` - Conversion logic, validation, scale interaction, atmosphere, and particles

## Run Locally

No build tools or dependencies are required.

1. Open `index.html` directly in a browser, or start a local server in this folder.
2. Enter a temperature and choose its unit.
3. Press **Convert Temperature**, or adjust the temperature scale at the bottom.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
